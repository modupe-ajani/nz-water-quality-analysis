# nz-water-quality-analysis
# New Zealand Water Quality Analysis

## Project Overview

This project explores New Zealand environmental water-quality data using data cleaning, exploratory data analysis (EDA), and statistical modelling. The main objective is to investigate patterns in water quality and develop a model to predict water temperature.

## Objectives

* Explore the structure and quality of the water-quality dataset.
* Investigate missing values and patterns in environmental measurements.
* Examine relationships between water temperature and selected environmental and geographical variables.
* Build and evaluate a statistical model for predicting water temperature.

## Methods and Tools

* **Programming:** Python
* **Data analysis:** Pandas, NumPy
* **Visualisation:** Matplotlib, Seaborn
* **Statistical modelling:** Ordinary least squares (OLS) regression
* **Environment:** Jupyter Notebook

## Water Temperature Prediction

The modelling workflow uses historical observations to train a regression model and evaluates its performance on data from later years. Predictors include decade, month, latitude, catchment area, and catchment height.

## Skills Demonstrated

Data cleaning, exploratory data analysis, data visualisation, feature selection, regression modelling, and time-based training and testing.

## Project Status

The project is being prepared as a reproducible data science portfolio project. Further documentation and results will be added as the analysis is organised.
